# EXP-0078: fast-decode block mode 27 (`cdec`)

Status: pre-registered hypothesis written before measurement; results below.

## Motivation

On the research corpus Bite decodes 3–10x slower than the references (Bite
0.59–0.86 s; zstd -19 0.11 s, Brotli 11 0.14 s, xz -9e 0.23 s on the reference
machine). The cost comes from the adaptive arithmetic and context-model
decoders used by modes 10–25. No Bite point is on the size/speed Pareto
frontier.

## Hypothesis

A new block mode 27 can keep most of Bite's parsing advantage while removing
adaptive coding from the decode loop. It reuses the wide-history
(16 MiB window) `WideMatchIndex` match finder with a cost-based parser, and
codes the result with static per-block tANS tables:

* zstd-style sequences (literal length, match length, offset) with bucketed
  codes plus raw extra bits, and a four-entry recent-distance cache whose
  codes 0–3 replace the offset;
* one backward bitstream with three interleaved tANS states for the
  sequence codes;
* literals either as four interleaved order-0 tANS streams (bulk decoded, then
  16-byte wild copies), or as a static context model: up to 64 clustered tANS
  tables selected by a key over the 1–6 preceding decoded bytes (generic rank
  map; no file-type dispatch), chosen by exact encoded size per block;
* a forward optimal parse priced from the previous encoding's actual tables
  (greedy seed plus three iterated passes, exact-selected by size);
* a decoder loop with no model updates, bounded copies with 32 bytes of
  slack, multi-byte (16/8-byte) match copies, and full bounds validation.

Predictions, pre-registered:

1. Research-corpus aggregate below zstd -19 (3,384,473 bytes on the
   reference machine), ideally below xz -9e (3,360,808).
2. Process-harness decode time within 1.5x of zstd -19, measured as a
   same-machine ratio in this cloud environment.
3. `cmax`, `cfast`, `cbwt` and every historical mode stay byte-identical,
   because id 37 returns before any historical path executes.

The decision is KEEP if (1) holds against zstd -19 and (2) holds. Otherwise
it is REJECT, with the numbers recorded.

Assigned identifiers: block mode 27, `compress_linked_blocked` entropy_parse
id 37, CLI preset `cdec`.
